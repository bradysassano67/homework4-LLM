# Homework 4 - LLM API

This project demonstrates how to interact with a large language model using code instead of a web interface.

## What this does
- Connects to the Gemini API
- Sends multiple prompts
- Prints the outputs

## How to run

1. Install dependencies:
pip install -r requirements.txt

2. Set API key:
set GEMINI_API_KEY=YOUR_KEY_HERE

3. Run:
python app.py
