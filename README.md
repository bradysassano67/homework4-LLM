# Homework 4 - LLM API

This project shows how to interact with a large language model through code instead of using a webpage.

## What the program does
- Connects to the Groq API
- Sends multiple prompts to an LLM
- Prints the responses in the terminal

## Files
- `app.py` : main Python script
- `requirements.txt` : dependency list
- `README.md` : project description

## How to run
1. Install dependencies:
   python -m pip install -r requirements.txt

2. Set your API key:
   set GROQ_API_KEY=YOUR_KEY_HERE

3. Run the program:
   python app.py

## Sample Output
--- Prompt 1 ---
INPUT:
Explain what a large language model is in 2 simple sentences.

OUTPUT:
A large language model is a type of AI trained on large amounts of text to understand and generate human language...
